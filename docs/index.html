BIPCircle stablecoin treasury verifier

Reads the live on-chain treasury balance for a BIPCircle stablecoin straight from the XRP Ledger — no login, no trust in BIPCircle's servers. Trust roots are pinned in this page's source (and in the open-source verifier).

Tenant:  

This page shows the live on-chain issued supply (the treasury's liability) and links you to the raw XRP Ledger so you can see it yourself. It does not by itself prove reserves ≥ supply — the full cryptographic check (signed bank-witness reserves vs on-chain supply, Merkle + ES256) needs the bank-service feed and runs in the CLI:
npm i -g @lazyjackorg/bipcircle-verifier && bipcircle-verify --xrpl-tx <hash> --tenant <id> --network <net>

Sister project: agentbip-verifier (research-record anchor chain). Source: bipcircle-verifier.
